To run this project:

| 目的 | 命令 (NPM) | 说明 |
| :--- | :--- | :--- |
| **日常开发** | `npm run docs:dev` | 实时热更新，用于写文档。 |
| **模拟部署** | `npm run docs:build` | **关键步**：将 Markdown 转为 HTML 静态文件。 |
| **最终核对** | `npm run docs:preview` | **关键步**：预览 `build` 后的成品。 |
