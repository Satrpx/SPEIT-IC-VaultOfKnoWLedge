# 课前准备

这份清单是给 workshop 开始前使用的。你不需要把所有工具都提前装到完美状态，但至少要保证自己能顺利进入课堂主线。

## 你需要准备什么

- 一台可正常联网的电脑
- 管理员权限或能安装软件的权限
- 至少 10GB 可用磁盘空间
- 能稳定使用 2-3 小时的电源和网络
- 一个文本编辑器，推荐 VS Code

## Windows 同学

### 目标

在 workshop 开始前，至少做到下面两件事：

1. 你能在 Windows 里执行 `wsl --status`
2. 你能打开 Ubuntu 终端

### 建议的自检命令

在 Windows PowerShell 或 Windows Terminal 中执行：

```powershell
wsl --status
wsl --list --verbose
```

如果还没有安装 WSL，可以执行：

```powershell
wsl --install
```

如果想显式安装 Ubuntu：

```powershell
wsl --install -d Ubuntu
```

### 第一次打开 Ubuntu 后建议做的检查

在 Ubuntu 终端执行：

```bash
cat /etc/os-release
pwd
whoami
```

这样你能确认：

- 自己确实进入了 Linux 终端
- Ubuntu 版本是什么
- 当前用户是谁

### 推荐但非必须：配置 WSL 镜像网络

如果你经常遇到 WSL 下载慢、代理不生效、端口转发奇怪的问题，可以在 Windows 中创建：

```text
C:\Users\<你的用户名>\.wslconfig
```

写入：

```ini
[wsl2]
networkingMode=mirrored
dnsProxy=true
autoMemoryReclaim=gradual
```

然后在 Windows 里执行：

```powershell
wsl --shutdown
```

这一步不是课堂硬要求，但对于网络环境复杂的机器通常有帮助。

## macOS 同学

### 目标

你不需要 WSL。macOS 自带类 Unix 终端环境，课上可以直接跟 Linux 命令主线。

### 建议的自检命令

在 Terminal 中执行：

```bash
uname -a
which zsh
which bash
```

### 建议提前安装 Homebrew

如果你还没有 `brew`，可以先按官网安装。安装后自检：

```bash
brew --version
```

### 一个非常重要的提醒

不要对系统 Python 执行：

```bash
sudo pip install ...
```

macOS 的系统 Python 不是给你做实验环境的。课上我们会讲环境隔离，项目依赖应该进 Conda 或其他独立环境。

## VS Code 建议

推荐提前安装 VS Code，并准备好这些插件：

- `Python`
- `GitLens`
- `Remote Development`

这样你在课堂里会更容易同时看文件、看终端和连接 WSL。

## 网络自检

如果你怀疑自己网络不太稳，课前可以做一轮最小检查。

```bash
ping -c 2 pypi.org
curl -I https://github.com
echo $http_proxy
echo $https_proxy
```

如果 `curl` 很慢，或者 `ping` 连域名都解析不出来，先怀疑网络和代理，不要先怀疑 Python。

## 其他事项

下面这些如果来不及，可以放到 workshop 里再做：

- 安装 Miniconda
- 配置 `apt` / `pip` / `conda` 镜像源
- 配置 Git SSH Key
- 跑通 demo 项目
- 预留一个 `~/projects` 目录
- 提前注册好 GitHub 账号

## 课前自查

只要你能做到下面三件事，课堂就基本能跟上：

1. 终端能打开
2. Windows 同学能进入 WSL Ubuntu，或 macOS 同学能进入 Terminal
3. 你知道自己当前是在哪个系统里执行命令
