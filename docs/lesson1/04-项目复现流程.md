# 项目复现流程

- 路线 A：speit-workshop-demo-repo
- 路线 B：公开 GitHub 项目 `streamlit/streamlit-example`

两条路线背后的工作流是一样的：

`系统工具 -> Git -> Conda 环境 -> pip 依赖 -> 运行项目 -> 验证 -> 最小改动`

## 路线 A：speit-workshop-demo-repo

### Step 0：准备目录

```bash
mkdir -p ~/projects
cd ~/projects
```

### Step 1：安装系统工具

Ubuntu / WSL：

```bash
sudo apt update
sudo apt install -y git curl wget
```

macOS：

```bash
brew install git wget
```

### Step 2：配置 Git 身份

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global --list
```

### Step 3：安装并初始化 Miniconda

```bash
cd ~
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
source ~/.bashrc
conda --version
```

如果 `conda activate` 后面报错，补做：

```bash
conda init bash
source ~/.bashrc
```

### Step 4：创建并激活环境

```bash
conda create -n workshop-demo python=3.11 -y
conda activate workshop-demo
which python
which pip
```

### Step 5：配置 pip 镜像

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip config list
```

### Step 6：克隆 Workshop Demo 仓库

```bash
cd ~/projects
git clone https://github.com/ybwowen/speit-workshop-demo-repo.git
cd speit-workshop-demo-repo
```

### Step 7：安装依赖

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Step 8：运行项目

课堂 demo 的入口一般是：

```bash
streamlit run main.py
```

### Step 9：验证项目是否真的起来了

浏览器默认访问：

```text
http://localhost:8501
```

如果浏览器没打开，可以在终端确认：

```bash
curl -I http://127.0.0.1:8501
```

### Step 10：做一个最小修改并提交

建议改标题或欢迎语，然后执行：

```bash
git status
git diff
git add .
git commit -m "Personalize workshop demo"
git log --oneline --graph --decorate -5
```

### 练习

尝试在自己的 Github 账号中新建一个仓库，并把代码传到自己的仓库中。可以先自行摸索一下如何操作

提示：可以使用 `git remote` 相关的指令

## 路线 B：公开 GitHub 项目

推荐项目：

`https://github.com/streamlit/streamlit-example`

### 完整命令

```bash
mkdir -p ~/projects
cd ~/projects
git clone https://github.com/streamlit/streamlit-example.git
cd streamlit-example
conda create -n my-first-app python=3.11 -y
conda activate my-first-app
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Fallback 方案

### GitHub 挂了

直接使用资料包里的：

```text
offline-assets/speit-workshop-demo-repo.zip
```

### pip 很慢

优先切镜像；如果还不行，使用资料包里的 `offline-assets/wheelhouse`。

如果你已经有可用的 Python 环境，执行：

```bash
pip install --no-index --find-links=../offline-assets/wheelhouse -r requirements.txt
```

如果你连 Miniconda 都只能走离线路径，那么 backup 路线默认直接使用离线安装器自带的 base 环境，见：

```text
offline-assets/README.md
```

### Miniconda 下载失败

优先看资料包里的 `offline-assets/` 目录，再使用对应安装脚本：

```bash
bash ./Miniconda3-latest-Linux-x86_64.sh -b -p ~/miniconda3-offline
```

### Streamlit 端口冲突

```bash
streamlit run main.py --server.port 8502
```

或：

```bash
streamlit run streamlit_app.py --server.port 8502
```

## 完成标准

如果你能做到下面 4 件事，恭喜你，你已经完成了本次 workshop 的全部任务！

1. 成功进入正确终端和目录
2. 成功建好并激活 conda 环境
3. 成功安装依赖并跑起页面
4. 成功做出一次最小代码修改并 `git commit`
