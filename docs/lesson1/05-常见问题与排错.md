# 常见问题与排错


## 常见错误速查

### `command not found`

先检查：

- 软件是否真的安装了
- 当前环境是否激活
- PATH 是否正确

### `Permission denied`

先检查：

- 是不是系统级操作
- 文件有没有执行权限
- 当前目录是否正确

不要一看到权限报错就无脑 `sudo`。

### `ModuleNotFoundError`

优先怀疑：

- 包没装
- 包装到了错误环境
- 当前运行的 `python` 不是你以为的那个

### `git push` 失败

区分三类：

- 认证失败：看 SSH / Token
- 网络失败：看代理 / 网络
- 分支冲突：先 `git pull`

## 最后的办法：删环境重建

如果某个 Conda 环境已经被你改到自己都说不清楚装了什么，最省时间的做法通常不是继续补丁，而是重建。

```bash
conda deactivate
conda remove -n workshop-demo --all -y
conda create -n workshop-demo python=3.11 -y
conda activate workshop-demo
```

环境是可重建的。时间更贵。
