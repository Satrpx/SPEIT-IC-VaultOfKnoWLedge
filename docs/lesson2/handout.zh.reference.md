## 启动与退出

**启动 Qwen Code**
```bash
qwen
```

**继续之前的会话**
```bash
qwen -c
# 或者
qwen --continue
```

**退出 Qwen Code**
- 输入 `/exit` 或 `/quit`
- 或按 `Ctrl+D`（空输入时）

> **💡 小提示：什么是 Session？**
>
> Session（会话）是 Qwen Code 保存的一次完整对话历史。包括：
> - 你问过的所有问题
> - AI 的所有回答
> - AI 读取/修改过的文件
>
> 使用 `qwen -c` 可以继续之前的会话，AI 会记得之前说过的话。适合：
> - 中断后继续工作
> - 隔天继续同一个项目
> - 切换到另一个终端继续

## 特殊按键

在交互模式中，有以下特殊按键：

| 按键 | 作用 |
|------|------|
| `!` | 进入 Shell 模式执行命令（空输入时） |
| `?` | 显示键盘快捷键帮助（空输入时） |
| `Shift+Tab` | 切换审批模式（plan → default → auto-edit → yolo） |
| `Ctrl+C` | 取消当前请求，按两次退出 |
| `Ctrl+D` | 退出应用（空输入时） |
| `Ctrl+L` | 清屏 |
| `Ctrl+J`、`\+Enter` | 换行 |

## Slash 命令

在交互模式中，以 `/` 开头的命令有特殊功能：

### 会话管理

| 命令 | 作用 |
|------|------|
| `/help` | 显示所有可用命令 |
| `/clear` | 清除终端屏幕内容 |
| `/compress` | 压缩对话历史，节省 Token |
| `/summary` | 生成对话历史摘要 |
| `/quit` 或 `/exit` | 退出 Qwen Code |

### 认证与设置

| 命令 | 作用 |
|------|------|
| `/auth` | 切换认证方式 |
| `/model` | 切换使用的模型 |
| `/settings` | 打开设置编辑器 |
| `/language` | 查看或更改语言设置 |
| `/theme` | 更改视觉主题 |

### 工具与扩展

| 命令 | 作用 |
|------|------|
| `/tools` | 显示当前可用工具列表 |
| `/skills` | 列出可用的技能 |
| `/mcp` | 列出配置的 MCP 服务器和工具 |
| `/extensions` | 列出当前激活的扩展 |
| `/approval-mode` | 更改工具审批模式 |

### 信息

| 命令 | 作用 |
|------|------|
| `/about` | 显示版本信息 |
| `/stats` | 显示当前会话详细统计 |
| `/memory` | 管理 AI 的指令上下文 |
| `/copy` | 复制最后输出内容到剪贴板 |

## 审批模式（Approval Modes）

使用 `Shift+Tab` 切换以下模式：

| 模式 | 说明 |
|------|------|
| **plan** | 仅显示计划，不执行操作 |
| **default** | 每个操作都请求确认 |
| **auto-edit** | 自动批准编辑工具 |
| **yolo** | 自动批准所有操作（慎用！） |

## 上下文管理（Context）

**什么是上下文（Context）？**

上下文是 AI 在对话中"记住"的所有信息，包括：
- 你之前说过的话（问题、指令、背景）
- AI 之前的回答
- AI 读取过的文件和项目结构
- 你们之间的整个对话历史

**上下文的重要性：**
- 上下文越多，AI 越了解你的项目
- 但上下文太长会消耗更多 token，响应变慢
- AI 可能"忘记"早期的内容或开始混乱

**如何给模型提供上下文：**

1. **在项目目录中启动**
   ```bash
   cd my-project
   qwen
   ```
   AI 会自动读取项目结构和相关文件。

2. **直接告诉 AI 背景信息**
   ```
   这是一个 Flask 项目，使用 SQLAlchemy 操作数据库。
   我想添加一个用户登录功能。
   ```

3. **引用具体文件内容**
   ```
   请看 app.py 第 30 行的 login 函数，
   我想修改它的认证逻辑。
   ```

4. **提供相关代码片段**
   ```
   我有一段代码想让你修改：
   [粘贴代码]
   请帮我添加错误处理。
   ```

**上下文压缩：**
当对话历史太长时，Qwen Code 会消耗更多 token。使用以下方法压缩上下文：

```bash
# 压缩对话历史，节约 token
/compress

# 清除对话历史，重新开始
/clear

# 或者退出后重新进入
/exit
qwen
```

**什么时候清除上下文？**
- 切换到一个完全不相关的任务
- 感觉 AI 开始"混乱"或忽略你的指令
- 对话超过 10 轮

## 权限管理（Permission）

Qwen Code 在执行某些操作时会请求权限：

| 操作 | 权限提示 | 建议 |
|------|----------|------|
| 读取文件 | 自动允许 | 安全 |
| 修改文件 | 请求确认 | 先确认修改内容 |
| 运行命令 | 请求确认 | 确认命令安全 |
| 删除文件 | 请求确认 | 仔细确认 |
| 网络请求 | 请求确认 | 确认目标网站 |

**安全提示：**
- 始终审查 AI 要执行的命令
- 不要允许访问敏感文件（如 `.env`、密码文件）
- 使用版本控制（git）以便回滚
